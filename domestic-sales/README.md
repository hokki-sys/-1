# 국내 판로 개척 작업공간 (Domestic Sales)

강해무역이 수입하는 **중국산 민물장어(로스트라타 주력 + 자포니카)** 를
국내에서 판매할 곳 — 신규 거래처와 판매 채널 — 을 찾기 위한 정보를 모으는
작업공간입니다. 후보 발굴 → 조사 → 접촉 → 거래 개시까지의 과정을 이 폴더
안에서 관리합니다.

## 구성

| 파일/폴더 | 역할 |
|---|---|
| [`channels.md`](channels.md) | 국내 판매 채널 지도 — 채널별 특징, 진입 방법, 준비물, 리스크 |
| [`leads.csv`](leads.csv) | 잠재 거래처 마스터 목록 (파이프라인 관리의 중심 파일) |
| [`contact-log.csv`](contact-log.csv) | 업체별 접촉 이력 (전화·메일·미팅·샘플 발송 기록) |
| [`templates/lead-profile.md`](templates/lead-profile.md) | 유망 업체 상세 조사용 프로필 템플릿 |
| `notes/` | 조사 노트 보관 (`YYYY-MM-DD-주제.md` 형식 권장) |

## 사용 방법

1. **후보 등록** — 판매 가능성이 있는 업체를 발견하면 `leads.csv`에 한 줄
   추가합니다 (상태: `후보`).
2. **조사** — 유망한 업체는 `templates/lead-profile.md`를 복사해
   `notes/업체명.md`로 저장하고 상세 조사 내용을 채웁니다 (상태: `조사중`).
3. **접촉** — 전화·메일·미팅 등 모든 접촉은 `contact-log.csv`에 기록하고,
   `leads.csv`의 상태·최근접촉일·다음액션을 갱신합니다.
4. **관리** — 주기적으로 `leads.csv`를 훑으며 다음액션이 밀린 업체를
   챙깁니다.

## `leads.csv` 컬럼 정의

| 컬럼 | 설명 |
|---|---|
| 업체명 | 상호 (그룹사는 법인 단위로) |
| 채널 | `channels.md`의 채널 분류 중 하나 |
| 지역 | 본사 또는 납품처 소재지 |
| 희망공급제품 | 냉동필렛 / 양념구이(가바야키) / 활장어 등 |
| 예상월물량 | kg 단위 추정치 (모르면 비움) |
| 담당자 / 직책 / 전화 / 이메일 / 웹사이트 | 연락 정보 |
| 상태 | 아래 상태값 중 하나 |
| 우선순위 | 상 / 중 / 하 |
| 최근접촉일 | `YYYY-MM-DD` |
| 다음액션 | 다음에 할 일 한 줄 (기한 포함 권장) |
| 메모 | 자유 기입 |

**상태값**: `후보`(발견만 함) → `조사중` → `접촉시도` → `상담중`(미팅·샘플·견적
진행) → `협상` → `거래개시` / 그 외 `보류`, `부적합`
