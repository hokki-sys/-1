# VIETFISH 2026 출장 공간 (호치민 수산물박람회)

호치민 수산물박람회(VIETFISH 2026) 참관 + 양산도 호치민 진출 시장조사 출장에 관한 모든 자료를 모아두는 공간입니다.
박람회 준비물, 호텔·일정, 현장에서 수집한 자료(명함·견적·메모), 주말 시장조사 기록을 여기에 쌓아갑니다.

## 출장 개요

| 항목 | 내용 |
|---|---|
| 박람회 | VIETFISH 2026 (제27회 베트남 국제 수산 전시회) |
| 일시 | **2026년 8월 19일(수) ~ 21일(금)** |
| 장소 | SECC (Saigon Exhibition & Convention Center) — 799 Nguyen Van Linh, 7군, 호치민 |
| 주말 미션 | 8/22(토)~23(일) **양산도 호치민 진출 현지 시장조사** (푸미흥 한인타운·1군 등) |
| 권장 숙박 | 8/18(화) 체크인 ~ 8/23(일) 심야 or 8/24(월) 체크아웃 (5~6박) |
| 공식 사이트 | <https://vietfish.com.vn> · 방문 등록: <https://vietfish.com.vn/en/register-event> |
